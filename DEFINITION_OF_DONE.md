# Definition of Done
An item moves to Done only when all of these are true:
- [ ] All acceptance criteria in the issue are met
- [ ] A pull request was reviewed and approved by someone other than the author
- [ ] Tests pass, or manual test steps are documented in the PR
- [ ] A second person verified the behaviour against the acceptance criteria
- [ ] README/docs updated if behaviour or setup changed
- [ ] Issue updated with a short completion note and linked PR
